## Stärken-Fragebogen

- **Teil A – Fähigkeiten:** 21 Aussagen in fünf Bereichen, danach eine Auswahl der drei wichtigsten Fähigkeiten
- **Teil B – Arbeitsweise:** fünf Aussagen
- **Teil C – Interessen:** Themenfelder und zwei Freitextfelder
- **Teil D – freiwillig:** Typ aus dem 16Personalities-Test
- **Auswertung:** Stärkenprofil und Zusammenfassung, druckbar oder als PDF zu speichern (für das Talentportfolio)

## Datenschutz

Alle Antworten bleiben im Browser des jeweiligen Geräts (localStorage). Es werden keine Daten an einen Server übertragen.
